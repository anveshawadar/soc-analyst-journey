# Day 1 Notes

## OSI Model

1. Physical Layer
- Transfers raw bits

2. Data Link Layer
- MAC addresses
- Frames

3. Network Layer
- IP addresses
- Routing

4. Transport Layer
- TCP and UDP

5. Session Layer
- Connection management

6. Presentation Layer
- Data formatting/encryption

7. Application Layer
- HTTP, DNS, FTP
